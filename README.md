# 🎉 Eventora - Event Management Website

A modern, responsive Event Management Website built using HTML, CSS, and JavaScript. The website showcases event planning services, portfolio, client testimonials, and a consultation booking form.

## 📌 Project Overview

Eventora is a one-page event management website designed to provide users with an attractive and user-friendly platform to explore event planning services. The website is fully responsive and suitable for desktop, tablet, and mobile devices.

---

## 🚀 Features

- Responsive Navigation Bar
- Hero Section with attractive heading
- Services Section
- Portfolio Gallery with category filters
- Client Testimonials
- Contact Information
- Event Consultation Booking Form
- Responsive Footer with Social Media Links
- Mobile-Friendly Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons
